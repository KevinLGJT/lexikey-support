词伴技术支持

词伴将中英文键盘与离线词汇学习放在一起。你可以浏览词条、管理收藏，并在学习中心查看每日任务、已学单词和学习记录。

如何添加键盘？

打开系统“设置 → 通用 → 键盘 → 键盘 → 添加新键盘”，选择“词伴”。随后在支持第三方键盘的输入框中，长按地球图标切换到词伴。

需要允许完全访问吗？

基础输入可以离线使用。若要让键盘读取本机每日待学单词、共享收藏和学习进度，请在系统设置中为词伴开启“允许完全访问”。词伴不会上传输入内容。

为什么密码框里无法使用？

密码框、部分专用输入框，以及禁止第三方键盘的 App 会切换到系统键盘。这由 iOS 和使用键盘的 App 决定。

在哪里查看已学和接下来要学的词？

在主 App 打开“学习中心”。“今日安排”显示当前队列和后续安排；“我的词汇”提供已学词的搜索、筛选与学习轨迹；“学习记录”可按日期查看已完成的新学与复习词表。

词条为什么有时没有音标或例句？

词伴优先显示随包词库的完整原文。部分扩展词义匹配使用 CC-CEDICT 简要释义，其原始内容可能没有英文音标、搭配或例句。词义匹配仅用于学习参考。

学习记录会同步吗？

当前版本不提供云端账户同步。学习记录保存在本机；取消收藏和切换学习词库不会删除已有进度。卸载 App 会移除本机应用数据。

联系开发者

本支持网站由 GitHub Pages 托管。打开网页或使用反馈区时，GitHub 可能按其隐私声明处理网络访问及账号信息。这与词伴 App 内的离线处理分开。

请通过 词伴反馈区 提交问题。提交反馈需要 GitHub 账号；反馈内容公开可见，请勿填写私人信息。

反馈时可提供 App 版本、设备型号、iOS 版本、复现步骤和不含私人内容的截图。请勿发送密码或其他敏感输入内容。
